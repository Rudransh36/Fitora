OAuth Configuration Notice

To activate direct social login in your environment, configure the OAuth credentials in your backend configuration file.

GOOGLE_CLIENT_ID=your_client_id_here
GOOGLE_CLIENT_SECRET=your_client_secret_here
GOOGLE_CALLBACK_URL=http://localhost:5000/api/auth/google/callback
In accordance with security standards, credentials are stored securely via environment variables and never exposed in client source code.
